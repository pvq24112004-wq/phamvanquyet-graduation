# Thiệp mời tốt nghiệp Phạm Văn Quyết

## Cấu trúc chuẩn để upload lên GitHub Pages

- `index.html`
- `assets/css/style.css`
- `assets/js/app.js`
- `assets/images/...`
- `assets/audio/fairytail.mp3`

Upload **toàn bộ nội dung bên trong thư mục** lên thư mục gốc của repository. Không đổi tên `index.html`.

## Xem trên máy tính
Mở thư mục bằng VS Code và chạy `Open with Live Server`.

## Xem trên điện thoại
Sau khi upload GitHub Pages, dùng link dạng:
`https://TEN-TAI-KHOAN.github.io/TEN-REPO/`

Nhạc chỉ phát sau khi người xem bấm `Mở thiệp`, phù hợp quy định của trình duyệt điện thoại.
